# Fiji LLM Provider 0.5.1

[English guide](https://github.com/liuhaoqiu/fiji-llm-provider/blob/main/README.md) |
[简体中文说明书](https://github.com/liuhaoqiu/fiji-llm-provider/blob/main/README.zh-CN.md)

One extension JAR adds DeepSeek, SiliconFlow, Volcengine Ark and NVIDIA to Fiji
Chat, with dynamic model lists and configurable assistant execution limits.

## Changes in this release

The default tool-calling budget is now **1000 rounds per user message**, increased
from 300 in 0.5.0. Existing saved values take precedence: if you previously saved
300, open **Help > Assistants > LLM Execution Settings...**, set 1000 and save.
Reopen Fiji Chat to apply changes to an existing assistant.

English and Simplified Chinese guides are included, with language-switch links.
The Windows build script accepts the Fiji installation path rather than assuming
a developer's path.

## Install

Install Fiji Chat first, close Fiji, then copy `fiji-llm-provider-0.5.1.jar` into
the installation's `jars` directory. Disable older copies of this extension and
restart Fiji. Do not replace the core `fiji-llm-*.jar`.

Configure the service in **Manage API Keys...**, run **Refresh LLM Models...**,
then select the provider and model in **Fiji Chat...**.

## Compatibility and validation

Verified with Windows 11, Fiji/ImageJ 2.18.0 / ImageJ 1.54p, Fiji Chat
0.2.0-SNAPSHOT, Java 21.0.7 and LangChain4j 1.21.0. See the repository's
`docs/VERIFICATION.md` for the exact core fingerprint and validation results.
Upstream API changes may require an extension update.

The nine local suites cover provider discovery, model lists, authentication
sequencing, transport, images, timeouts and the actual assistant loop. The
1000-round boundary is tested with synthetic tools, without a real API key.
The release does not include credentials, conversations, model caches or Fiji's
dependencies. No automatic resume/checkpoint feature is included.
