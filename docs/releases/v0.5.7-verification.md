# Release verification: 0.5.7

**English** | [简体中文](v0.5.7-verification.zh-CN.md)

Fifteen local verification suites passed through the supplied release build
script. Existing provider, catalog, multimodal, context retention/compaction,
streaming, 1000/1001 tool-round, timeout and macro regressions remain included.
The new cold-JVM regression creates an actual common-pool worker in the macro
group, then covers idle completion, renamed workers, active work, unrelated
common-pool activity and private-pool isolation. The same fixture with the
installed 0.5.6 JAR reproduces the indefinite completion wait.

Additional isolated GUI checks passed: an actual inherited ImageJ StackWindow
idle selector (including rename and normal closure), consecutive macros, a real 31-second
wait, duplicate prevention, real input/error dialogs and non-macro delegation.
Actual Cellpose passed on a 128×128 synthetic image and on a 3000×3000 RGB
working copy resized from the reported task's locally archived preview.
The large run exported 288 ROIs, wrote a count table and returned
`success` in 15.05 seconds including process
startup. A subsequent macro also completed. This count exercises a nonempty
execution path; it is not a validated biological count of the original image.

The private preview is neither uploaded nor included in the source/binary
package. No hosted inference API or API key was used. Synthetic large fixtures
are available without private data; nonempty ROI verification can optionally use
your own local RGB fixture via the documented build argument.
