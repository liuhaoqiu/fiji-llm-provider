# Fiji LLM Provider 0.5.17

[English](v0.5.17.md) | **简体中文**

本次汇总发布自上一个公开版 0.5.12 之后、经过本地审阅的 0.5.13–0.5.17 改进。Fiji LLM Provider 通过一个扩展 JAR 添加 DeepSeek、硅基流动、火山引擎 Ark 和 NVIDIA，并改善 Fiji Chat 的执行反馈、进度展示和长任务体验。

## 自 0.5.12 以来的更新

- **明确区分错误弹窗：**正文区分普通参数输入弹窗与明确报告的宏错误弹窗，显示脚本名称和限长原因；`<analysisId>` 等尖括号定位标记作为代码完整保留。重复查询不反复刷同一条状态。
- **隔离非关键展示故障：**展示回调异常不再吞掉工具结果或阻断后续模型轮次，真实任务和 API 错误仍正常传递。纯图像、图文和多内容工具结果保留原始载荷。本地开发期间尝试的后台回执解析已经撤销，活动监测沿用开始/结束元数据和 API 事件。
- **更有用的执行诊断：**启动冲突时返回已知的占用脚本/运行身份；保留启动失败原因。委托上游执行的普通脚本明确标为“宏版本核验器未覆盖”，避免误称从未执行。
- **编辑器兼容处理：**最近的 Script Editor 有运行任务时，新建脚本使用独立编辑器窗口，避免已复现的插件新建标签触发 Script Editor 1.4.3 `Writer is null` 的路径；保留上游执行服务。

## 实测任务耗时缩短

在同一条红色通道细胞核计数请求、同一张 3000×3000 图像的多轮本地测试中，近期完整任务约 **5–9 分钟**，此前审阅的 0.5.12 运行约 **11 分 37 秒**；近期最快一次约 **5 分 5 秒**完成。

| 本地测试版本 | 首个流事件至最终报告显示 | 工具调用次数 | 保存确认里程碑 |
| --- | --- | --- | --- |
| 0.5.12 | 11 分 37 秒 | 137 | +558 秒 |
| 0.5.15 | 6 分 37 秒 | 89 | +384 秒 |
| 0.5.16 | 5 分 5 秒 | 85 | +286 秒 |
| 0.5.17 | 9 分 4 秒 | 112 | +521 秒 |

这是完整任务的实测观察，尚非控制变量基准测试，也不是固定加速承诺。模型/服务商响应、调参次数、重复运行和工作区状态存在差异；0.5.17 的错误格式修复本身不改变推理或分割速度。累计的收尾等待与交互改进有助于任务更顺畅地完成，但单次耗时仍会波动。工具调用次数不等于工具调用轮数。

本次 0.5.17 交付经过独立核验：268 个唯一标签、268 行测量和 268 个对应 ROI 一致，文件哈希、导出源图像素、测量及导出 QC 均通过检查；也实际验证了错误定位标记显示和自动错误弹窗处理。这证明工程交付一致性，不是生物学分割准确性证明。

## 保留的能力

四家 API、动态模型列表、原有密钥保险库、默认**每条消息 1000 轮工具调用**、按模型管理上下文与本地完整记录、自动整理和中断恢复、正文进展/折叠日志/最终报告三部分展示、初始化后的明确命令参数、稳定脚本目标与精确快照、显式保存本地分析交付包均保留。分析方法与参数仍由模型选择，已有保存设置优先。

## 安装或升级

1. 先安装 Fiji Chat，保存当前工作并关闭 Fiji。
2. 下载 `fiji-llm-provider-0.5.17.jar`，可用 `SHA256SUMS.txt` 核验。
3. 放入 Fiji 的 `jars/` 目录，移出或停用旧 provider 扩展，只保留一个活动版本；保留原版 `fiji-llm-*.jar` 和 Script Editor JAR。
4. 重启，通过 **Help → Assistants → Manage API Keys...** 管理密钥；通过 **Help → Assistants → Refresh LLM Models...** 刷新模型，然后重新打开模型选择窗口。

源码 ZIP 用于查看或构建，安装不需要。模型/接入点须支持工具调用，图像输入还须支持视觉，列表中的模型并非全部同时支持二者。交付包需要显式调用导出工具，成功后在正文显示实际目录。

## 验证与范围

最终 0.5.17 构建通过 **24 组本地回归**。新增字面量渲染测试在未修改的 0.5.16 上失败，在 0.5.17 上使用 Fiji Chat 真实渲染器通过。安装目录复查覆盖服务/类来源、摘要渲染、图像/多内容回调、展示故障注入隔离和聊天历史展示。此前 0.5.15 基线通过六项隔离原生 GUI 集成；此次一行展示修改未重复这六项检查。本地测试套件使用合成工具/图像与本地服务，上述用户实际运行核查单独列示。

验证环境：Windows 11、Java 21.0.7、Fiji/ImageJ 2.18.0 / 1.54p、Fiji Chat `0.2.0-SNAPSHOT`（提交 `f73180448c64c83edeb995dd96156d1dd68f7896`）、LangChain4j 1.21.0、Script Editor 1.4.3。原版 Fiji Chat 和 Script Editor JAR 未修改。这是确切构建的验证，不保证所有未来上游版本。服务商错误/超时仍可能发生，执行核验不证明空白状态复现或科学准确性。
