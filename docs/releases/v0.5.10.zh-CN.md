# Fiji LLM Provider 0.5.10（本地版）

[English](v0.5.10.md) | **简体中文**

增加初始化后明确参数执行、保留原图的宏框架、独立二维标签/原图强度测量、非破坏 QC/CSV、可直接操作的对话框 ID 和精确脚本执行核验。保留默认 1000 轮及原有展示/上下文能力。

保存并关闭 Fiji，将 `fiji-llm-provider-0.5.10.jar` 替换旧扩展放入 `jars`，重启后新开聊天。保留 Fiji Chat 和 Script Editor 本体。新宏桥接需要本扩展运行。

十九组本地测试、三项隔离 GUI 集成通过；仍需用户重复真实任务评价工具采用和科学分析效果。详见[工作流指南](../zh-CN/WORKFLOW.md)及[验证](../zh-CN/VERIFICATION.md)。
