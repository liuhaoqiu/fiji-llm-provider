# Fiji LLM Provider 0.5.19

[English](v0.5.19.md) | **简体中文**

## 修复：未知或畸形工具名不再直接中断请求

此前，模型返回不存在的工具名（实际出现过混入 DSML 标签的名称）会触发 SDK 默认异常并终止当前请求。异常工具没有被执行，但需要用户手动输入“继续”。

现在为 **DeepSeek、硅基流动、火山引擎 Ark 和 NVIDIA** 配置 SDK 已有的未知工具名处理接口，返回明确的 **unknown_tool / executed: false**，让模型下一轮自行选择真实可用的工具。

- 不猜测、剥离标签、改名或执行未知工具，也不重新解释其参数。
- 保留原始调用 ID/名称用于协议关联；同批合法工具及此前已完成结果保持可用。
- 处理器不重放已完成操作，不引入独立的请求重试机制。
- 纠正仍受**原有有限轮数预算**约束：默认每条消息1000轮，保存设置优先。持续请求不存在的工具仍可能到达上限，不保证所有在线模型均能纠正。
- 真实工具/API 错误、取消、上下文管理和展示沿用原行为；扩展之外的内置服务商仍使用原版 Fiji Chat 服务。

## 改动范围

与0.5.18相比，JAR中只有 **ProviderAssistantService.class** 和版本清单变化。其他类及资源逐字节一致，包含0.5.18脚本快照核验条修复。原版 Fiji Chat / Script Editor JAR 未修改；没有添加分析专用方法、追踪规则或科学准确性保证。

继续保留四家动态模型目录、原有加密密钥管理、长任务上下文预算/整理/本地记录、正文进展 / 折叠日志 / 最终报告、显式执行输入、稳定脚本目标及分析包导出。

## 安装或升级

1. 先安装 Fiji Chat，保存工作并关闭 Fiji。
2. 下载本页 **fiji-llm-provider-0.5.19.jar**，可用 **SHA256SUMS.txt** 核对。
3. 放入 Fiji 的 **jars/**，停用旧 provider 扩展，只保留一个活动版本。保留原版 Fiji Chat / Script Editor JAR。
4. 重启 Fiji。密钥通过 **Help → Assistants → Manage API Keys...** 配置；刷新模型通过 **Help → Assistants → Refresh LLM Models...**，完成后重新打开模型选择器。

源码 ZIP 用于查看或构建，安装不需要。代理任务要求模型支持工具调用，图像输入还要求视觉能力；出现在目录中不等于支持全部能力。

覆盖四家服务商同步/流式、畸形及普通未知名称、混合法/非法调用、调用关联和记忆、不猜测执行或重放、正文进展及单次最终回复、原有有限轮数、原服务行为、本机 HTTP JSON/SSE 往返，以及多模态、展示异常隔离、错误渲染和聊天历史。
