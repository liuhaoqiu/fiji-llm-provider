**English** | [简体中文](v0.5.10.zh-CN.md)

Add explicit initialized-command inputs, a source-preserving macro scaffold, independent 2D label/source-intensity measurements, non-destructive QC/CSV output, actionable dialog IDs and exact-script execution evidence. Preserve default 1000 rounds and the existing presentation/context behavior.

Save work, close Fiji, replace the older provider extension in `jars` with `fiji-llm-provider-0.5.10.jar`, then restart and open a new chat. Keep core Fiji Chat and Script Editor JARs. New macro bridges require this extension at runtime.
