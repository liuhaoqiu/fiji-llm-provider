# Fiji LLM Provider 0.5.16 (local)

**English** | [简体中文](v0.5.16.zh-CN.md)

One production class changes: StagePresentation. When an existing blocked_by_dialog receipt has a nonempty text error_dialog, progress now says execution reported an error and is waiting for the error dialog to be dismissed, with the existing bounded reason summary. Ordinary input dialogs retain their original wording. Repeated polls are deduplicated; a normal-dialog-to-error transition is visible. Tool results, execution status, task behavior, API providers and monitoring are unchanged. Background receipt monitoring remains removed.

All 24 local suites passed, including normal/error dialogs, nested receipts, empty/null/non-text fields, bounded summaries, deduplication, terminal states, real image/multipart callbacks, display fault injection and actual chat-panel/history presentation. The six native GUI integrations from 0.5.15 were not rerun for this presentation-only change; no execution/editor implementation changed. No hosted inference or user images were used. All production class bytes except StagePresentation match 0.5.15 exactly. Local only; close Fiji before installing.
