## 助手执行验证

- 真实 SciJava 发现机制选中扩展助手服务，并注入实际服务商、工具和图像服务依赖。
- 四个新增服务商及本体 ChatGPT、Claude、Gemini、Ollama 可在无图形验证环境中实例化。
- 未修改本体复现原有 100 轮后的错误。
- 每个新增服务商均完成同步和流式的 150 轮循环；每条新流式消息获得新预算。
- 使用默认配置的流式助手完成 1000 轮工具调用并返回最终答复；
  请求 1001 轮时报告限制错误，且不会执行第 1001 轮工具。
- 自定义上限 3 生效；同一回复中的多个工具仍计为一轮。
- 图像负载、图像访问策略、规范化、传入记忆、默认请求参数及工具错误处理保持连接。
- 原生设置模块正确初始化、保存和取消；服务未激活时说明设置无法应用。
- 无关服务商委托给已安装本体，保留原上限和本地图像策略。

## 服务商回归验证

其余测试覆盖动态目录和模型移除、旧缓存处理、元数据、原生密钥管理器等待与取消、
空列表启动循环、多模态记忆、两种 API 协议、流式响应、工具回复、推理内容、
图像负载原样传递、鉴权失败和手动 Ark 接入点保存。

超时测试分别将响应头延迟 65 秒，并在另一个场景持续发送 65 秒 SSE 保活消息。
四个服务商的同步和流式工厂均通过；原版 Chat Completions 对照复现 60 秒超时，
原版 Responses 对照完成请求。验证了有效的 30 分钟响应和 15 秒连接配置、
上游 504 错误及 Ark 元数据回归。

## 范围

测试使用确定性本地模型/工具和回环地址服务器，不读取真实 API 密钥，
不调用付费推理，不执行用户宏，不修改打开的图像或已保存轮数。

这些结果验证列明环境中的集成行为，不证明真实账户权限、所有模型的工具/视觉能力、
生成宏的科学正确性或未来 Fiji Chat 版本兼容性。实现说明中的公开目录查询
与上述本地测试分开记录。
