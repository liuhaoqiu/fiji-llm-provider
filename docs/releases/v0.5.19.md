# Fiji LLM Provider 0.5.19

**English** | [简体中文](v0.5.19.zh-CN.md)

## Fixed: recover from unknown or malformed tool names

A model response containing a nonexistent tool name, including an observed name contaminated with DSML markup, previously triggered LangChain4j's default unknown-tool exception and stopped the current request. The invalid tool was not executed, but the user had to continue manually.

For **DeepSeek, SiliconFlow, Volcengine Ark and NVIDIA**, the extension now configures the SDK's existing unknown-tool-name strategy. It returns a structured **unknown_tool / executed: false** result, allowing the model to select an exact valid name on its next round.

- It does not guess, trim markup from, rename or execute an unknown tool, nor reinterpret its arguments.
- The original tool call ID/name is retained for correlation. Valid tools in the same batch and earlier completed results remain available.
- The handler does not replay completed tools or add an independent request-retry mechanism.
- Corrections consume the **existing finite tool-round budget**: default 1000 per message, with saved preferences taking precedence. Persistent invalid calls can still reach that limit; recovery by every hosted model is not guaranteed.
- Existing genuine tool/API error handlers, cancellation, context management and display behavior are retained. Built-in providers outside this extension keep the original Fiji Chat service.

## Minimal scope

Compared with 0.5.18, only **ProviderAssistantService.class** and the version manifest differ in the JAR. All other classes and resources, including the saved-script verification badge fix, are byte-identical. Original Fiji Chat and Script Editor JARs remain unchanged. This release adds no analysis-specific method, tracking rule or scientific-quality guarantee.

The extension still provides four-provider dynamic model catalogs, the existing encrypted key manager, long-task context budgeting/compaction and local records, public progress / folded activity / final report presentation, explicit execution inputs, stable script targets and analysis-bundle export.

## Install or upgrade

1. Install Fiji Chat first, save your work and close Fiji.
2. Download **fiji-llm-provider-0.5.19.jar** from this release; optionally check its SHA-256 with **SHA256SUMS.txt**.
3. Copy the JAR into Fiji's **jars/** directory. Disable older provider extension JARs and keep one active extension. Retain the original Fiji Chat and Script Editor JARs.
4. Restart Fiji. Configure credentials via **Help → Assistants → Manage API Keys...**. Refresh catalogs via **Help → Assistants → Refresh LLM Models...**, then reopen the model chooser.

The source ZIP is for inspection/building, not needed for installation. Agent tasks need a tool-capable model; image input also needs vision support. A model's presence in the catalog does not certify either capability.

## Verification and limits

**26 distinct regression suites passed**: 25 suites in the full build plus a separately compiled/run JSON/SSE wire suite. **Seven installed-JAR checks passed.** The exact observed DSML-contaminated name reproduces the interruption against unchanged 0.5.18 and recovers in 0.5.19.

Coverage includes all four provider service configurations in synchronous and streaming flows; malformed/ordinary unknown names; mixed valid/invalid batches; original call correlation and memory; no guessed execution or completed-action replay; preserved public progress and one final response; existing finite round limits; unchanged original-service behavior; real local Chat Completions JSON/SSE round trips; multimodal callbacks, display-failure isolation, error rendering and chat/history presentation.

Tests used synthetic models/tools and local servers. **No hosted inference or user image analysis was run for this fix.** Native GUI suites were not repeated. These checks verify the integration, not scientific accuracy or successful self-correction by every remote model. No inference or segmentation speedup is claimed.

Tested environment: Windows 11, Java 21.0.7, Fiji/ImageJ 2.18.0 / 1.54p, Fiji Chat 0.2.0-SNAPSHOT commit f73180448c64c83edeb995dd96156d1dd68f7896, LangChain4j 1.21.0, Script Editor 1.4.3. Future upstream builds require compatibility checks. Private logs/images, credentials and dependency JARs are not bundled.
