# Fiji LLM Provider 0.5.18

**English** | [简体中文](v0.5.18.zh-CN.md)

## Fixed: final verification badge points to the saved script

After an analysis bundle was exported, a later cleanup or auxiliary script could replace the script shown in the final report's execution-evidence badge. The exported files were unchanged, but the displayed association was wrong.

The final badge now uses the execution evidence captured by the **most recent successful bundle export**. For example, exporting `analysis.ijm` and then running `cleanup.groovy` keeps the badge on the saved `analysis.ijm` snapshot. It is explicitly labeled **Last saved script snapshot evidence**.

- Later editor changes do not become claims that the current editor bytes were executed.
- Failed or invalid exports do not replace the last successful snapshot; a later successful export becomes the selected snapshot.
- The saved filename is retained even if the editor tab is renamed afterward.
- Without a successful export, the existing latest-script behavior is retained.
- Ordinary-script languages outside the exact-byte macro checker, including Groovy, remain `not_monitored`; this is not a claim of failure. Consult their run receipts.

This is a small presentation fix: only `StagePresentation.class` and the version manifest differ from the 0.5.17 JAR. It does not modify the original Fiji Chat or Script Editor JARs, change scientific methods or model instructions, or accelerate inference.

## Capabilities retained

The extension still provides DeepSeek, SiliconFlow, Volcengine Ark and NVIDIA APIs, dynamic model catalogs, the existing encrypted key manager, **1000 tool rounds per message by default**, model-aware context budgets and automatic compaction with full local records, public progress / folded activity / final report presentation, explicit command inputs and analysis-bundle export. Existing saved preferences take precedence.

## Install or upgrade

1. Install Fiji Chat first. Save your work and close Fiji.
2. Download `fiji-llm-provider-0.5.18.jar` from this release. Optionally verify its SHA-256 with `SHA256SUMS.txt`.
3. Place the JAR in Fiji's `jars/` directory. Disable older provider-extension JARs and keep one active extension. Keep the original Fiji Chat and Script Editor JARs.
4. Restart Fiji. Configure credentials at **Help → Assistants → Manage API Keys...**. Update catalogs at **Help → Assistants → Refresh LLM Models...**, then reopen the model chooser.

The source ZIP is for inspection/building and is not required for installation. A listed model must support tool calling for agent tasks; image input additionally requires vision support. Listing a model does not certify these capabilities.

## Verification and limits

The final build passed **24 local regression suites** and installed-JAR checks for service/class origin, error rendering, display-failure isolation, image/multipart callbacks and chat/history presentation. The real-receipt regression reproduces the wrong badge in unchanged 0.5.17 and passes in 0.5.18. Tests cover cleanup after export, later edits, failed exports, multiple exports, paused output, unsupported languages and request isolation. Native GUI suites were not repeated for this display-only change.

Two subsequent user-run tasks were independently reviewed: a nuclei task delivered **267 labels = 267 CSV rows = 267 ROIs**; a cells-and-nuclei task delivered **283/258 labels**, each matching its CSV/ROI counts. File hashes, source pixels, measurements and exported QC were checked. The second task also compacted context and continued through execution, export and final output. These establish observed engineering consistency, not biological accuracy or clean-state replay. Model-generated script/API mistakes and report arithmetic errors still occurred.

Observed complete task durations were about **7 min 15 s** and **16 min 30 s**, respectively. They involve different tasks and model decisions and are not a controlled speed comparison or a speedup claim for 0.5.18.

Tested on Windows 11, Java 21.0.7, Fiji/ImageJ 2.18.0 / 1.54p, Fiji Chat `0.2.0-SNAPSHOT` commit `f73180448c64c83edeb995dd96156d1dd68f7896`, LangChain4j 1.21.0 and Script Editor 1.4.3. Future upstream builds require compatibility checks; provider failures/timeouts remain possible. Private task logs, images and credentials are not included.
