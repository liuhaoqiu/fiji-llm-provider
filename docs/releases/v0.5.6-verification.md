# Release verification: 0.5.6

**English** | [简体中文](v0.5.6-verification.zh-CN.md)

All fourteen local verification suites passed using the release build script.
The original thirteen suites remain unchanged; the new macro scope checks cover
real child waits, child failures and unknown waiting children, alongside console
maintenance separation. Existing checks cover providers, catalogs, multimodal
messages, actual 1000/1001 tool-round boundaries, context compaction/recovery,
streaming activity, 65-second delayed responses and SSE idle protection.

Additional isolated integration checks passed through the real installed
Script Editor/SciJava macro pipeline: consecutive macros, a real 31-second wait,
duplicate prevention, input dialogs, macro errors after dismissal and original
script-service delegation. Actual Cellpose on a 128×128 synthetic image returned
success and allowed a subsequent macro. Candidate timing was about 10.5 seconds
including process/environment startup; this is not a model-only benchmark.

The identical synthetic Cellpose fixture through the original execution service
printed CELLPOSE_FIXTURE_DONE but still returned running after 30 seconds.
The historical user-run thread dump independently showed evaluation had returned
and the Script Editor controller was sleeping in its cleanup wait.
