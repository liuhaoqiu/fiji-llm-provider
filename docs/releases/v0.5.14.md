# Fiji LLM Provider 0.5.14 (local)

**English** | [简体中文](v0.5.14.zh-CN.md)

Fix a regression introduced by 0.5.13: its activity callback eagerly called ToolExecution.result() on all tools, which throws for image/multipart results. Status observation now filters applicable tools first and reads text elements through resultContents(). Presentation uses the same content-aware reader. The original content list is never modified or replaced. The old installed JAR reproduces the exact failure through a real AI-service image-tool callback. New tests verify image-only, text+image, multipart status text, unchanged downstream callbacks/memory, and final response delivery.

23 local suites and six GUI integrations passed. No hosted inference or user images were used. Existing 0.5.13 status/editor improvements and 1000-round default are retained. This is a local hotfix, not a GitHub release. Save and close Fiji before installing the new JAR; keep one active extension and retain core/editor JARs.
