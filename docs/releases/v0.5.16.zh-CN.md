# Fiji LLM Provider 0.5.16（本地）

[English](v0.5.16.md) | **简体中文**

只修改一个生产类 StagePresentation。既有 blocked_by_dialog 回执明确包含非空文本 error_dialog 时，正文改为“执行报错，等待关闭错误弹窗”，并复用已有的限长原因摘要。普通参数输入弹窗保留原提示；重复查询去重，同一任务由普通弹窗转为错误弹窗时可见。工具结果、执行状态、任务行为、API 接入及活动监测不变，后台回执解析继续撤销。
