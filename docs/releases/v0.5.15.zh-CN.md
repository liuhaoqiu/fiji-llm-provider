# Fiji LLM Provider 0.5.15（本地撤销版）

[English](v0.5.15.md) | **简体中文**

撤销 0.5.13 新增的后台任务回执解析。StreamActivity 的源码及类文件均精确恢复为 0.5.12：监测只读取工具开始/结束元数据与 API 活动，不读取工具返回内容。这是撤销该功能，并非只在纯文本转换外增加捕获。

将非关键工具状态/展示回调与下游结果交付隔离。展示层发生 RuntimeException、LinkageError 或 AssertionError 时记录日志，不改变原始工具结果，不阻断结果交付和下一模型轮次。实际工具/API 回调位于隔离区之外，真实任务失败不会被变成成功。既有阶段展示保留对图像/多内容安全的文本读取。JVM 致命错误不冒充可恢复展示异常。

旧 0.5.14 JAR 可通过展示端抛异常复现任务中断。真实 AI-service 故障注入确认三类异常下，下游仍接收原始结果，模型/记忆内容一致，并产生一次最终回复；纯图像、图像加文本、多文本回调回归也通过。全部二十四组本地验证和六项隔离 GUI 检查通过，未使用在线推理或用户图像。

保留 0.5.13 其他修复：忙碌诊断、核验范围提示及独立编辑器窗口。四家 API 实现、默认设置、许可证和上游 JAR 不变。仅本地安装，未发布 GitHub。
