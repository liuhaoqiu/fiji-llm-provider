The original nine suites still cover discovery, authentication sequencing,
startup recovery, catalogs, multimodal memory, both HTTP protocols, all four
providers, real 1000/1001 tool-round boundaries and real 65-second delayed
responses/SSE keepalives. The additional `ContextBudgetVerificationMain` covers:

- Exact UTF-8 byte boundaries and estimated-token boundaries.
- All four provider HTTP builders rejecting oversized requests before transport.
- Manual 1M windows when a provider omits context metadata.
- Automatic organization of growing sync/streaming tool contexts without replay.
- Exact image archive round-trip and clearly identified large-result excerpts.
- A context failure after tools and partial thinking have already been received.
- The original Fiji ChatMessagePanel retaining visible checkpoint text and activity,
  and saving the paused assistant response in a Conversation.
- Same-chat continuation without automatically replaying completed tools.

The additional `ProgressDisplayVerificationMain` reproduces the 0.5.2 channel
error and verifies checkpoint detail routing, concise stage output, post-compaction
thinking/tool events, and final-answer delivery.

The chat-panel check runs headlessly against the installed core component and
callback sequence. It is not a visual/manual acceptance of a live long-running
microscopy task. No real API key, hosted inference request or user-image mutation
is used in these checks. See [Context behavior and limits](../CONTEXT.md).

The new JAR contains eight SciJava registrations, source notices and license
texts, and does not bundle runtime dependencies, test classes or local archives.
The historical [0.5.1 verification](v0.5.1-verification.md) is retained.
