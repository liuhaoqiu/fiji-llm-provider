# 工作流工具（0.5.10）

[English](../WORKFLOW.md) | **简体中文**

针对已发生的问题：重复弹参数窗口、QC 标注图误作输入、标签编号当作荧光强度，以及最终宏编辑后未回放。保留模型选择和默认 1000 轮；科学参数由模型与用户决定。

## 明确参数执行和宏模板

先用 `fiji_command_parameters` 获取真实命令类及区分大小写的输入名。`fiji_command_run_with_inputs` 接收 `command`、`inputs_json`、`image_id`，初始化命令后应用明确类型的参数，不走输入采集或持久化参数预处理。用 `fiji_command_inputs_status` 查询同一运行，不重复启动；第三方命令内部的界面/错误仍可能出现。此路径跳过命令后处理器，需要检查输出与回执。

回执包含实际输入值、原图 ID、执行前后像素哈希、命令耗时和新观察到的图像 ID。耗时包含命令内部等待，不是 GPU 内核耗时。`actual_device=not_reported_by_command` 明确表示后端未报告实际设备，不能把 GPU/CUDA 请求参数当作已验证硬件。

`fiji_command_macro_template` 为恰好生成一张二维标签图的命令生成完整 ImageJ 宏框架：保留当前原图、复制分析通道、执行明确参数、按回执取得唯一新图，再对原图测量。应运行最终脚本的精确版本后再报告已执行。宏需要安装本扩展 0.5.10 或更新版本；无新图或出现多张新图会明确失败，不猜选输出；并发手动操作也可能影响这个检查。

Cellpose v3 的类为 `fiji.plugin.appose.cellpose.cp3.CellposeAppose`，输入例如 `cp_model`、`cell_diameter`、`torchVersion`、`useGPU`、`return_ROIs`。桥接使用 Java 输入名，不混用旧宏的小写关键字，应以当前安装的元数据为准。v3 的 `nuclei` 与 Cellpose-SAM 不同。直径、面积和阈值需结合图像选择；本扩展不强加生物学筛选。若无需 ROI 导出，可设 `return_ROIs=false`，避免第三方命令向已有 ROI Manager 追加内容。

## 原图和标签测量

`fiji_image_extract_channel` 独立复制一个二维平面的通道，保留源图。RGB 的 1/2/3 分别是红/绿/蓝，灰度用 1。复制图携带来源与初始像素哈希；新分析工具拒绝被悄然改写的复制图及带本工具 QC 标记的展示图。原有工具和任意宏仍能改图，这不是全局写保护。

`fiji_label_measure` 明确指定不同的 `source_image_id`、`label_image_id` 和 `source_channel`。按非零唯一整数标签计数，支持编号空缺；测量像素面积、原图原始强度、质心和边缘接触，不施加面积筛选。要求尺寸一致且为单平面；尺寸一致不代表已验证生物学配准。

完整 CSV 使用唯一文件名保存在本地上下文归档目录，同时显示独立表格和原图副本上的非破坏轮廓叠加。此测量工具保留已有全局 Results 与 ROI Manager。信号覆盖率和面积覆盖率分母不同，都不是细胞核召回率；不自动判定碎屑或科学准确性。

## 精确脚本版本的执行核验

宏运行回执包含 `executed_source_sha256`。`fiji_script_validation_status` 将活动脚本内容与当前 JVM 会话的最近执行记录比较；编辑使旧记录不再匹配，失败运行不计成功。存在相关工具证据时，最终报告会独立显示执行核验状态。

精确代码在当前会话运行成功，不等于已验证从全新图像/ROI/Results 状态复现，也不等于科学结果正确。记录仅在当前会话有效；重启后需重新运行。只改文件名而不改代码，不会使匹配的执行记录失效。

## 范围与验证

新助手工具用于本扩展的四家服务商，不替换 Fiji Chat 或 Script Editor 本体。宏桥接需要本扩展的 SciJava 上下文。测试使用合成命令与图像，并核对真实 Cellpose 参数初始化，不执行推理；仍需用户重做真实任务，评价模型能否有效采用新工具及实际分析效果。
