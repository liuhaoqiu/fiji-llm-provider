# 0.5.23 验证

[English](../VERIFICATION.md) | **简体中文**

**26 组回归在一次构建中全部通过。** 新增的检查覆盖 0.5.19 之后的每一项修改：思考阶段的停止；DeepSeek 图像细节及其对记忆、估算和其他服务商无影响；核验记录在标签位置变化后仍跟随脚本；脚本文件的精确保存与不静默覆盖；用 ImageJ 自身的参数解析器验证真实 Cellpose-SAM 命令的宏键名；运行状态工具的有界等待；汇报协议中的两种报告语言；脚本编辑不产生正文行；命令接受预处理过的通道而分析交付包仍然拒绝。

开发期间用 DeepSeek 在同一张图像上运行了四次真实任务，实际用到了原图细节的图像、双语报告、不弹对话框的宏键名、脚本文件保存和更简洁的聊天正文。

**未验证的部分。** 有界等待只用模拟的状态工具测试过，没有对接 Fiji Chat 本体真实的状态工具。预处理通道这条路径在真实任务中没有被走到。本版没有运行原生 GUI 套件。`detail=high` 是在交给 SDK 的请求里核对的，没有抓取网络数据包。这些检查都不涉及科学准确性：四次真实任务中模型选择了不同的方法，对同一张图像报告的细胞数分别是 3022、3012、5230 和 3697。

自动化测试使用合成模型、合成工具和本地服务，不使用 API 密钥、在线推理或用户图像。

环境：Windows 11、Java 21.0.7、Fiji/ImageJ 2.18.0 / 1.54p、Fiji Chat 0.2.0-SNAPSHOT（提交 1dea483ee7285efb86689902b4cae56dcd66a549）、LangChain4j 1.21.0、Script Editor 1.4.3。未来上游构建仍需兼容性检查。不包含私有日志/图像、密钥或依赖 JAR。
