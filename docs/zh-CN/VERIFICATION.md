新增 StreamStatusVerificationMain 验证：

- 如实区分等待 API 和等待工具；输出重置空闲计时，结束后不继续提示。
- 本地 HTTP 服务器先发响应头，再无正文数据或仅发送保活注释。
- 空闲 SSE 正文只触发一次超时；持续数据和长时间同步工具回调继续运行。
- 中断后保留部分运行日志、暂停回复、阶段检查点和同对话记忆。
- 重复错误或迟到的完成回调不会重复暂停回复，也不会重跑请求或工具。
- 通过真实 Responses 模型和 AiServices 处理空 response.incomplete 事件。
- 续接记忆移除空助手占位消息，完整归档仍保留。

同一任务淘汰回归独立运行于已安装的 0.5.4，准确触发“请求没有恢复任务”的断言；0.5.5 通过。
这些是本地模拟测试，不等同于真实托管推理或用户显微图像工作流已手动验收。
测试不使用真实 API 密钥或用户图像。

新增 TaskRetentionVerificationMain 还覆盖真实 TokenWindowChatMemory 图像淘汰、
