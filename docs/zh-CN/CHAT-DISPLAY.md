# 聊天展示（0.5.8）

[English](../CHAT-DISPLAY.md) | **简体中文**

本扩展创建的 DeepSeek、SiliconFlow、Volcengine 和 NVIDIA 助手默认启用新展示。
升级后重启 Fiji，重新打开 Fiji Chat 并发送新请求即可，无须额外菜单设置。
已结束的历史会话保留原来保存的样子。

## 正文中的阶段进展

**阶段进展 / Progress** 始终在正文中显示，无须展开日志。
助手可调用 `fiji_report_progress`，用用户的语言简述关键进展和下一步。
插件也会根据支持的工具返回值显示脚本更新、任务开始、完成或对话框阻塞等状态。
重复查询得到相同运行状态时不刷屏；频繁脚本编辑提示间隔至少 30 秒。
模型在工具调用前给出的公开正文，会在该工具轮次结束时作为阶段输出显示。

汇报工具绑定当前助手，不会串到其他聊天。它不额外调用模型，也不修改图像，
按正常工具轮数计数。描述性进展由模型决定何时汇报，执行状态提示由插件自动产生。

## 折叠运行日志

原有 **Thoughts and … tool uses** 区域继续保存推理、工具参数和原始返回值。
流式正文先缓冲，待判断为阶段消息或最终回答后再显示；不带可见文字的控制回调保留 Fiji
停止按钮的处理，草稿也保留在本地归档。上下文整理时，正文只显示简短的继续执行提示；
检查点摘录、JSON 和归档诊断留在日志或本地记录中。

## 最终报告

最后一轮模型输出结束后，原回答一次性显示在独立的 **最终报告 / Final report** 标题下，
前面的阶段进展继续保留。最后一轮正文会先缓冲，不再与之前的阶段文字混在一起。
插件不改写其中的结论。传输或上下文限制导致暂停时，标题改为 **任务暂停 / Task paused**，
保留并标明尚未完成的正文草稿。

Fiji 沿用原有会话格式保存显示正文与运行日志，重新打开已保存会话仍可看到这些内容。
模型记忆中的最终消息仍是模型原回答，不把界面标题和自动提示额外拼进去。
本地事件归档也保留展示事件，插件不另行请求模型总结进展；汇报遵循正常工具调用流程。

只更新扩展 JAR，Fiji Chat 和 Script Editor 保持原样。详见[发行验证](VERIFICATION.md)。
