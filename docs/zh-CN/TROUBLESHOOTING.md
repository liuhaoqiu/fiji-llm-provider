# 故障排查

[English](../TROUBLESHOOTING.md) | **简体中文**

| 现象 | 检查方法 |
| --- | --- |
| 没有新菜单或服务商 | 确认已安装 Fiji Chat、扩展位于 jars、只启用一个扩展版本，并已重启 Fiji。 |
| NoClassDefFoundError / NoSuchMethodError | 检查已验证的 Fiji Chat 和 LangChain4j 版本。上游接口变化可能需要重新构建或适配。 |
| 模型列表为空或过时 | 对正确服务执行 Refresh LLM Models，解锁密钥库并查看结果。旧缓存不代表已下线模型仍可调用。 |
| 弹出密码对话框 | 这是 Fiji Chat 密钥库解锁流程，输入密钥库密码而非 API 密钥。取消应结束命令。 |
| HTTP 401 | 检查所选服务和该服务的 API 密钥。 |
| HTTP 403 | 检查账户和模型权限。能看到目录不等于有推理权限。 |
| 找不到模型 | 刷新列表；Ark 用户还需核对完整模型或推理接入点 ID。 |
| 模型拒绝工具或图像 | 选择官方声明支持所需能力的模型。目录中的模型不一定支持聊天或视觉。 |
| request timed out / HTTP 504 | 检查服务商状态和网络。客户端超时设置不能覆盖上游服务端限制。 |
| exceeded ... tool calling round trips | 查看 LLM Execution Settings。已保存值优先于默认 1000；保存新值后重新打开 Fiji Chat。 |
| 执行设置显示 NOT ACTIVE | 另一服务可能获得更高优先级，或扩展与新本体不兼容。重新检查安装并运行验证。 |

## 长任务失败后

先保存有用的脚本、图像、ROI 和结果表。可识别的上下文超限、连接中断及空最终回复，
会生成 **Task paused — not completed（任务暂停，尚未完成）** 检查点。
在同一聊天中回复“继续”，并补充剩余要求。插件保留工作上下文和独立的完整本地归档，
不会自动重试请求、重放工具，或在 Fiji 重启后恢复外部进程。
其他错误仍可能使用 Fiji Chat 原有的错误处理。新消息有新的轮数预算，
但不会撤销已经执行的工具。详见[上下文与恢复](CONTEXT.md)。

## 加载旧历史记录时启动失败

较早版本的空回复可能留下无效的助手消息。如果
`Required service is missing: sc.fiji.llm.chat.ConversationService` 之前出现
`text cannot be null`，请检查底层历史加载异常。0.5.5 会防止产生新的空最终回复，
但不会自动修复此前损坏的历史。其他服务初始化错误也可能源于依赖不兼容等原因。

关闭 Fiji，先备份 `.fiji-chat-history`，再检查或隔离具体的损坏记录，保留其他会话。
不要一开始就删除全部历史，也不要在公开问题报告中上传私人聊天文件。

## 输入窗口不可见

检查其他 Fiji 窗口，或被遮挡的对话框。必要时按 Escape 取消等待中的命令，
然后重新打开菜单。图像或脚本尚未保存时，不要强制结束 Fiji。

## 提交问题

提供扩展版本、Fiji/ImageJ 和 Java 版本、Fiji Chat 与 LangChain4j JAR 版本、
所选服务商及模型、简短复现步骤和相关错误文本。隐去密钥、解锁密码和私人路径。
尽量使用合成图像或最小宏示例。原始聊天导出可能包含图像数据或私人任务内容，
通常无须提供。
